#  Veralis Evolution

> **Todo empieza contigo.**

Veralis Evolution es una plataforma web enfocada en el crecimiento personal mediante el uso de Inteligencia Artificial. El proyecto busca reunir herramientas para el desarrollo emocional, la creación de hábitos, el deporte, el aprendizaje y una comunidad donde las personas puedan evolucionar constantemente.

Actualmente el proyecto se encuentra en etapa de desarrollo del **frontend**, utilizando únicamente tecnologías web básicas.

#  Objetivo

Crear una plataforma moderna donde cualquier persona pueda mejorar diferentes aspectos de su vida mediante tecnología e Inteligencia Artificial.

Algunas funciones planeadas son:

- Desarrollo de hábitos.
- Seguimiento de objetivos.
- Asistente de IA.
- Comunidad.
- Progreso personal.
- Bienestar emocional.
- Rendimiento deportivo.
- Aprendizaje continuo.

# ▶️ Cómo ejecutar el proyecto

1. Clona el repositorio

```bash
git clone https://github.com/TU-USUARIO/veralis-evolution.git
```

2. Entra al proyecto

```bash
cd veralis-evolution
```

3. Abre el archivo

```
index.html
```

o utiliza la extensión **Live Server** de Visual Studio Code.

---

#  Flujo de trabajo con Git

El proyecto utiliza ramas para mantener un desarrollo organizado.

```
main
│
└── brayan
```

Flujo de trabajo:

1. Crear cambios en la rama `brayan`.
2. Realizar commits.
3. Hacer `push`.
4. Crear Pull Request.
5. Revisar los cambios.
6. Hacer Merge hacia `main`.
